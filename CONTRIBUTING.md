# Contributing to unwind.nvim

Thank you for your interest in contributing to `unwind.nvim`!

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/rkh-leung/unwind.nvim.git
   cd unwind.nvim
   ```

2. Run the test suite:
   ```bash
   ./scripts/test.sh
   ```

3. Run benchmarks:
   ```bash
   ./scripts/benchmark.sh
   ```

## Pull Request Guidelines

- Ensure tests pass with `./scripts/test.sh`.
- Follow standard Neovim / Lua style conventions.
- Document any new configuration options or user-facing commands.
